# SentinelARC API Reference

This document outlines the REST API endpoints exposed by the SentinelARC async core (`async_main.py`). The API is built using FastAPI and runs on port `8000` by default.

## Base URL
`http://localhost:8000`

---

## Endpoints

### 1. Health Check
Checks the status of the system and its agents.

**Endpoint:** `GET /health`

**Response:**
```json
{
  "status": "healthy",
  "agents_active": 7,
  "orchestrator_ready": true
}
```

### 2. Start Research
Initiates a new research task using the async orchestrator agent.

**Endpoint:** `POST /research`

**Request Body (JSON):**
```json
{
  "query": "string",
  "user_id": 123,
  "task_id": "default_task" // optional
}
```

**Response:**
```json
{
  "status": "task_received",
  "task_id": "default_task",
  "query": "query string"
}
```

### 3. General Chat (Streaming)
Handles general conversational queries using the Ollama proxy.

**Endpoint:** `POST /general_chat`

**Request Body (JSON):**
```json
{
  "query": "string",
  "model": "llama3", // or other configured Ollama models
  "history": [
    {
      "type": "user",
      "content": "previous message"
    }
  ],
  "user_id": 123
}
```

**Response:**
A `text/plain` streaming response containing chunks of text generated by the model.
